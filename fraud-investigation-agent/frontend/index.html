🔄 8-Stage LangGraph Agent Lifecycle

                WORKFLOW: Cyclic State Machine
            


            

                

                    01
                    
Trigger Ingestion

                    
Ingests high-risk scores, velocity spikes, disputes, or manual analyst alerts.

                    agent.state.TriggerEvent
                

                

                    02
                    
Subgraph Extraction

                    
Traverses TigerGraph 2-hop ego networks; extracts shared IPs, cards, and devices.

                    detect_shared_entities.gsql
                

                

                    03
                    
GraphRAG Context

                    
Hybrid retrieval matching historical vector cases and policy compliance documents.

                    ChromaDB + Cosine Sim
                

                

                    04
                    
Risk Assessment

                    
Calculates Bayesian fraud probability, uncertainty scores, and primary typology.

                    Bayesian Risk Scorer
                

                

                    05
                    
Pre-Evidence NBA

                    
Executes immediate interim containment (Step-Up Auth, Temporary Card Hold).

                    policy_engine.pre_nba
                

                

                    06
                    
Evidence Loop

                    
Cyclic self-reflection loop; fetches supplementary GSQL evidence if uncertainty > 0.20.

                    Dynamic GSQL Query
                

                

                    07
                    
Post-Evidence NBA

                    
Final Next-Best-Action selection routed through Tier 1/2/Compliance officer matrix.

                    Authorization Matrix
                

                

                    08
                    
SAR & Memory Commit

                    
Auto-generates FinCEN SAR narrative and indexes resolved case vector into memory.

                    FinCEN SAR + Memory Store

                        CRITICAL
                    

                    
Card-Not-Present Ring

                    
Signal: Shared hardware fingerprint, cross-merchant burst

                    
Pattern: 1 Device linked to >3 disparate bank accounts

                    
Query: detect_shared_entities.gsql

                    🚫 BLOCK_TRANSACTION
                


                

                    

                        TYP-002
                        CRITICAL
                    

                    
Account Takeover (ATO)

                    
Signal: Unrecognized device + foreign proxy/VPN IP jump

                    
Pattern: Rapid credential change followed by fund sweep

                    
Query: trace_fund_velocity.gsql

                    ❄️ FREEZE_ACCOUNT

                        HIGH

Pattern: Trust establishment then max credit depletion

                    
Query: find_similar_cases.gsql

                        CRITICAL

Pattern: Phantom entities sharing physical addresses & phones

⚙️ Enterprise Tech Stack Specifications

            


            

                

                    
🐯

                    
TigerGraph Engine

                    
Distributed GSQL graph traversal with 8 vertex types, 9 edge types, and sub-millisecond 2-hop neighbor extraction.

                

                

                    
🦜

                    
LangGraph Agent

                    
Cyclical state machine architecture with conditional self-reflection evidence loops and strict typed state schema.

                

                

                    
🧠

                    
ChromaDB GraphRAG

                    
Vector store indexing bank fraud policies, past case resolutions, and real-time semantic similarity embeddings.

                

                

                    
📋

                    
FinCEN Regulatory SAR

                    
Automated FinCEN-compliant Suspicious Activity Report drafting with full audit trails and multi-tier analyst sign-off.
